# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities through
[GitHub Private Vulnerability Reporting](https://github.com/dive-8978/astro-channel/security/advisories/new).
Do not include secrets, personal data, exploit details, or affected user data in
a public issue.

Include the affected URL or component, reproduction steps, expected and actual
behavior, impact, and any safe supporting evidence. Please use English or
Chinese.

We aim to acknowledge a complete report within seven calendar days. Timing for
validation and remediation depends on severity and reproducibility. This target
is not a service-level agreement or a paid bug-bounty commitment.

## Supported scope

Security fixes target the current public website and currently supported MA
releases. Historical prototypes, archived downloads, and unannounced features
may be removed instead of patched.

## Disclosure

Please allow time for validation and remediation before public disclosure. We
will coordinate a reasonable disclosure date with the reporter when the issue
is confirmed.
